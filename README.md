# 🌌 IC1101 App

IC1101 is an AI-powered Android app built with **React + Vite + Capacitor**.

## ✨ Features
- 🤖 AI chat assistant
- 📱 Native Android app (APK)
- 🎨 Clean & simple UI

## 📥 Download
Get the latest APK from the [official website](https://xkshatsharma.github.io/Project-IC1101/)

## 🛠️ Tech Stack
- React + Vite
- Capacitor (Android)
- JavaScript

## ⚙️ Setup
1. Clone the repo
2. `npm install`
3. Copy `.env.example` → `.env.local` and add your API key
4. `npm run dev` to run locally
5. `npm run build` + Capacitor sync for Android build
